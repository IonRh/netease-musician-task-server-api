# Server API

Standalone FastAPI service for registering account MD5 values and validating
client API keys.

The API key is generated by the server as:

```text
MD5(account_md5 + YYYYMMDDHH)
```

`YYYYMMDDHH` uses the server's local time. The key changes once per hour.

## Start

From the project root:

```powershell
.\.venv\Scripts\python.exe -m uvicorn server_api.main:app --host 0.0.0.0 --port 9000
```

From inside `server_api`:

```powershell
..\.venv\Scripts\python.exe -m uvicorn main:app --host 0.0.0.0 --port 9000
```

The default database is `server_api/data/server_api.db`.

## Count fields

- `today_listen_count`: current day's listen count
- `listened_count`: current day's listened count for the music
- `total_listen_count`: total listen count
- `total_listened_count`: total listened count
- `monthly_listen_count`: current month's listen count
- `monthly_listened_count`: current month's listened count
- `daily_listen_limit`: maximum listen count per day; `0` means unlimited
- `monthly_listen_limit`: maximum listen count per month; `0` means unlimited
- `enabled`: account switch; `1` enabled, `0` disabled

`count_date` and `count_month` are maintained internally for daily and monthly
counter rollover.

## Music statistics

List all registered Netease song or album IDs and their total listen counts:

```http
GET /api/listen_music
X-API-Key: any-api-key-stored-in-database
```

The request must include `X-API-Key`. Any API key currently stored in the
database is accepted; an unknown or missing key returns `401`.

Records with an empty `netease_item_id` are excluded. If the same music ID is
used by multiple accounts, `listened_count` is summed.

## Play queue

Get the next music to play. The service selects the record with the lowest
`listened_count` first. The account must have listened to music today, and the
music must not have reached its daily or monthly listened limit:

```http
GET /api/next
X-API-Key: any-api-key-stored-in-database
```

Response:

```json
{
  "account_md5": "e6891c34c808de2b846cb3290338a2a0",
  "netease_item_id": "123456",
  "today_listen_count": 0,
  "listened_count": 12
}
```

After playback finishes, report the exact record:

```http
POST /api/play/finish
Content-Type: application/json
X-API-Key: any-api-key-stored-in-database

{
  "account_md5": "e6891c34c808de2b846cb3290338a2a0",
  "netease_item_id": "123456"
}
```

The matching record's daily, monthly, total listen and listened counters are
increased by `1`. When a daily or monthly limit is reached, the request
returns `409`.

## Join

Register an MD5 and its client-generated API key:

```http
POST /api/join
Content-Type: application/json

{
  "account_md5": "e6891c34c808de2b846cb3290338a2a0",
  "apikey": "MD5(account_md5 + current YYYYMMDDHH)",
  "daily_listen_limit": 100,
  "monthly_listen_limit": 3000
}
```

The server regenerates the expected API key and compares it with the submitted
value. A mismatch returns `401`; a duplicate MD5 returns `409`.

## Authenticated requests

After joining, send the matching API key in the request header:

```http
X-API-Key: client-generated-api-key
```

Update a record:

```http
POST /api/update
Content-Type: application/json
X-API-Key: client-generated-api-key

{
  "account_md5": "e6891c34c808de2b846cb3290338a2a0",
  "netease_item_id": "123456",
  "daily_listen_limit": 100,
  "monthly_listen_limit": 3000
}
```

`/api/update` does not modify any listen counters. Counters are modified only
by `/api/play/finish`.

An account can only be re-enabled by calling `/api/join` again with the valid
current API key. `/api/update` cannot change `enabled`.

Get a record:

```http
GET /api/listen-records/{account_md5}
X-API-Key: client-generated-api-key
```

If the account is disabled (`enabled=0`), this endpoint returns
`404 record not found`.

Delete a record:

```http
DELETE /api/listen-records/{account_md5}
X-API-Key: client-generated-api-key
```

This endpoint is a soft disable operation. It sets `enabled` to `0` and keeps
the database record; it does not physically delete the record.

Invalid or missing API keys return `401`.
